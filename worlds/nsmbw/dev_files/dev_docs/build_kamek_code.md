# Build kamek code
## Setup
1) Follow install instructions to set-up kamek https://github.com/NSMBW-Community/Kamek-Ninja-Template/tree/master
2) Add your kamek directory as an environment variable called `KAMEK_PATH`.
3) Download this [zip](https://files.decomp.dev/compilers_20230715.zip) find `Wii/1.3` and copy all those files to `riivolution_patch/Kamek-Ninja-Template/cw`.


## Compile
1) run ```configure.bat``` from /Kamek-Ninja-Template-master/
